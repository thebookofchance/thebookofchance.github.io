# The Book of Chance — Literature Release Update v0.31

**Release approved by H on 23 November 2026.** Base: website v0.30.

## Installation

Extract the ZIP into the **root of the existing GitHub Pages repository** and overwrite matching files. Keep the folder structure. **Do not delete other files.** No Formspree endpoint, private configuration, or form-delivery setting is included.

## What this changes

- Public release status for all nine Library titles plus the separate Questions About Chance FAQ.
- Editorial-candidate labels removed from the current publication webpages and digital editions; cover artwork, stories and teachings preserved.
- Digital edition PDF/EPUB outputs and author metadata updated to describe the approved release while preserving existing filenames for backwards-compatible links.
- Search-engine `noindex` removed from the five newly approved publication/FAQ pages and the Guided Reading Journey, and those six URLs added to the sitemap. Duplicate `/reader/` remains `noindex` deliberately.
- Future `scripts/build_site.py` runs preserve release status, including updated catalogue data.
- Current release hashes and verification results recorded under `docs/`.

## After deploying

Verify the Library labels, a couple of PDF/EPUB downloads, the FAQ, Reading Journey, mobile reading and your existing forms. Search indexing can take time and is not guaranteed. Tagged PDF output is not a claim of PDF/UA certification or screen-reader validation.

Read `docs/Literature_Release_Notes_v0.31.md` and `docs/Literature_Release_Register_v0.31.json` for scope and audit information.
